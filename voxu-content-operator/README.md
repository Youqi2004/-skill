# VOXU Content Operator

Codex skill for VOXU Smart Ring official-account content operations.

## What It Does

- Rewrites online copy into VOXU Smart Ring Xiaohongshu and Douyin publishing copy.
- Preserves the source copy's expression, rhythm, and layout while replacing facts with VOXU-safe positioning.
- Generates VOXU-style social covers after the copy is approved and a source image is provided.
- Uses the official transparent VOXU logo asset by default.

## Skill Name

`voxu-content-operator`

## Install

Copy this folder to:

```text
C:\Users\ZZJL\.codex\skills\voxu-content-operator
```

or to:

```text
$CODEX_HOME\skills\voxu-content-operator
```

when `CODEX_HOME` is configured.
